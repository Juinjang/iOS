# DesignSystem Skill

## Overview
Rules and conventions for managing images, colors, Lottie animations,
and fonts in the DesignSystem module. All visual assets live here so
Feature modules can consume them without duplicating resources.

## When to Use
- Adding new images, colors, or Lottie files
- Creating reusable UI components
- Referencing assets from Feature modules
- Organizing new feature-specific assets
