# Naming Conventions Skill

## Overview
프로젝트 전체에서 사용하는 네이밍 규칙을 정의합니다.
API 호출 메서드명, Feature 내부 파일/폴더명의 일관성을 유지하기 위한 가이드입니다.

## When to Use
- API 클라이언트 메서드명을 작성할 때
- 새 Feature의 파일/폴더 구조를 생성할 때
- ViewModel, Model, View 파일명을 정할 때
- DependencyClient 프로퍼티명을 정할 때
